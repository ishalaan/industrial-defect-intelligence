NEU-CLS DATASET INFORMATION
===========================

Dataset name:
NEU-CLS

Application:
Computer Vision - multiclass image classification of hot-rolled steel surface defects.

Purpose in this project:
The dataset will be used to compare a classical machine learning approach
(HOG features + Support Vector Machine) against a deep learning approach
(Convolutional Neural Network) using the same images and evaluation protocol.

Public dataset source:
Figshare

Dataset page:
https://figshare.com/articles/dataset/NEU-CLS/28903550

Persistent DOI:

Figshare record details:

- Posted: 30 April 2025

- Download size: approximately 26.05 MB
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)

Original dataset provenance:

Original dataset authors identified by Northeastern University:
- Kechen Song
- Yunhui Yan

Dataset description:
NEU-CLS is designed for classification of surface defects on hot-rolled steel strip.
The official Northeastern University description lists six typical surface-defect
categories:

1. Crazing
2. Inclusion
3. Patches
4. Pitted surface
5. Rolled-in scale
6. Scratches

Dataset size and format:
- Total published images: 1,800
- Number of classes: 6
- Published images per class: 300
- Image resolution: 200 x 200 pixels
- Image content: greyscale
- Task: six-class defect classification

Important task scope:
NEU-CLS contains images belonging to six known defect categories.

It does NOT contain a normal or defect-free steel class.

Therefore, this project must NOT claim to determine whether an arbitrary steel
surface is normal or defective. The modelling task is:

"Given an image belonging to the represented defect dataset, classify it into
one of the six known defect categories."

The official Northeastern University source distinguishes:
- NEU-CLS: image-only dataset for defect classification
- NEU-DET: images with annotations for defect detection

This project uses NEU-CLS for classification and does not require object
detection or bounding-box prediction.


DATASET CHARACTERISTICS RELEVANT TO THE PROJECT
================================================

The original Northeastern University description notes that:

- defects within the same class can differ substantially in appearance;
- defects from different classes can have similar appearances;
- illumination and material changes can alter image greyscale characteristics.

These characteristics make the dataset suitable for comparing handcrafted
classical visual features with learned deep representations and for later
robustness and subgroup analysis.

PRE-MODELLING DATA AUDIT
========================

The local dataset was audited before model development.

Confirmed:
- 1,800 image files discovered
- 6 expected defect classes
- 300 images found for each class
- images readable
- expected 200 x 200 dimensions
- image pixel content is greyscale

Important issue identified:
One exact duplicate image pair was found within the Patches class:

- patches_101.jpg
- patches_105.jpg

The files were confirmed as exact duplicates.

Risk:
If duplicate copies were allowed to fall into different development and test
partitions, the test result could be artificially inflated through data leakage.

Planned treatment:
- Preserve the raw dataset unchanged.
- Exclude one redundant duplicate from the modelling manifest before creating
  the train/test partitions.
- Keep the decision explicit and reproducible rather than manually deleting
  the original file.
- The resulting modelling pool will therefore contain 1,799 unique images.

This duplicate finding should be reported in the final presentation as part of
the critical discussion of dataset integrity and leakage prevention.


OTHER AUDIT OBSERVATIONS
========================

The downloaded dataset contains annotation/non-image files in addition to the
classification images.

These are not required for the present task because this project performs
image-level classification rather than object detection.

Although the stored image files may be represented internally using RGB
channels, audit inspection showed greyscale image content. Preprocessing will
therefore convert images explicitly to a single greyscale channel so that this
decision is controlled and reproducible.

KEY LIMITATION TO RETAIN
========================

Performance on NEU-CLS should not be interpreted as evidence that a model will
generalise automatically to:

- defect-free steel;
- other defect categories;
- other steel grades;
- different factories;
- different cameras or inspection systems;
- substantially different illumination or production conditions.

The project therefore evaluates comparative performance on this benchmark,
not universal industrial defect-detection capability.
